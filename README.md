# Eisenhower AI releases

Installers and update files for [Eisenhower AI](https://apps.microsoft.com/detail/9NF14KJMWRM4),
an Eisenhower Matrix task manager that keeps every task as a Markdown file on
your computer.

- **Windows:** the easiest way to install is the
  [Microsoft Store](https://apps.microsoft.com/detail/9NF14KJMWRM4), which keeps
  the app up to date. The installer on the
  [latest release](https://github.com/AnilGoral/Eisenhower-AI-Releases/releases/latest)
  updates itself too: it asks before installing a new version.
- Each release lists its changes and the SHA-256 of every file.

This repository holds release files only. The app's source code is private.

Each installer is signed for the app's updater, and the app installs only
updates that carry that signature. `latest.json` on the latest release tells
installed apps which version is newest.
